# Grading a proof

Give each submitted proof one grade, **correct** or **incorrect**. A correct proof establishes every requested claim under the stated hypotheses. Accept any valid method. The reference proof and its checkpoints describe one route. Equivalent arguments can discharge the same obligations in a different order.

A correct conclusion with a material gap earns **incorrect**. Examples include a circular appeal to the result being proved, exchanging two limits without justification, applying a theorem beyond its domain, or omitting a requested direction or counterexample. Standard undergraduate results may be cited when the relevant hypotheses are established or directly given. Honor any restrictions in the problem. Brief routine algebra or a harmless typo is acceptable when the argument remains unambiguous.

Judge the mathematics in the submitted answer as written. For the first pass, inspect the entire visible answer. An output-limit flag records where generation stopped. A complete valid argument can earn credit even if later text is cut off. A missing essential step still counts as a gap. If a response contains incompatible mathematical claims about an essential step, judge whether it actually resolves the conflict.

For every incorrect grade, name the specific gap or error in the reason cell. For example, “The proof chooses a different cutoff for each x and never shows that one cutoff works for all x.” Leave a correct answer’s reason blank if desired.

Each problem statement, reference proof and difficulty rating in the bank is a draft awaiting independent human verification. The verification note beside a problem names any special issue to check. If a problem is ambiguous or the reference is flawed, pause that grade for adjudication. Do not count a suspected bank error as a model failure.

The review packet applies the same mathematical standard. It presents proofs in random order under opaque IDs. The condition key and raw responses stay in the run archive. Recognizable language or memory of a first proof may still provide clues. Keep the archive closed until review grading is complete.
